## Start menu (shell builder)
Translucent blue glass panel rising from the start button, about 300x455 image px:
- Header: user picture (orange gerbera here, i.e. our Sondra stand-in), user name in large
  white Franklin Gothic ("Sondra"), "switch user" under it; right side two round glossy buttons:
  red "shut down", amber "log off".
- Left column, pinned: big icons with title + subtitle: "Outlook Express / E-mail",
  "Word 2002 / Word Processor", "Explorer / Web Browser". Then a list with small icons (MFU):
  Winamp, Amazon, Messenger, Notepad, Dreamweaver, PowerPoint. Footer: "All Programs & Services >".
- Right column (slightly lighter glass): My Documents, My Pictures (bold), then folders
  "Susans Work", "January Pics", "My Stuff" (hover = thin red outline box, and a blue arrow
  marking a submenu); then Search, Control Panel, Help & Support, Run..., Windows Tour,
  Top 10 Tasks.
- For our OS keep only entries that open something we have (nothing dead): use our apps (Outlook,
  Word, Internet Explorer, Winamp, Messenger (im), Notepad if built, my Music, my Pictures &
  Videos, my Documents, my Computer, Control Panel, Help and Support, Search, Run...). Third-party
  product names (Amazon, Dreamweaver, PowerPoint) are out. "Windows Tour" may replay the video's
  demo sequence (?demo) or open Help; "Top 10 Tasks" opens Help on a tasks page.
- "All Programs & Services" opens the my Programs & Services window.

## my Programs & Services window (apps builder)
An explorer window (same chrome as my Music; toolbar adds a "Mail" button) titled
"my Programs & Services": task pane "program tasks" (Add new programs, Configure a program,
Remove a program, Search for updates); bar "Group programs by category ▾ / Arrange alphabetically
▾"; content = category tiles with big 3D glass icons and three entries each + "more...":
Accessories, Communications, Entertainment, Games, Imaging, Internet, Productivity.
List only programs that exist in our OS (each entry launches it); "more..." expands the
category. Small built-ins that make the categories honest are welcome if cheap: Calculator,
Notepad, Character Map, Paint (simple), and an original card game (a generic Klondike-style
solitaire is fine; no recreation of Microsoft's own Solitaire art). Program tasks open dialogs
(e.g. Add new programs -> a neutral "no programs available to add" page; Remove a program -> a
list that won't remove system programs).
